## Summary
In this lab we connected a multiplexer to a demultiplexer to create a rudimentary network switch. The module takes in four 4-bit inputs then routs them according to the selector bits.

## Lab Questions

### In plain English describe the function and use of a multiplexer.
A multiplexer takes multiple inputs and routes one of them to the output according to certain selection conditions.
### In plain English describe the function and use of a demultiplexer.
A demultiplexer takes a single input and routes it to one of a number of outputs according to similar selection conditions.
### What other uses might these circuits have? (Think Shannon’s)
These circuits can be used in conditional statements such as if and switch, as well as being useful for network traffic, directing packets of data from various sources to various outputs.
